# DSE launch sequence

A single self-contained page for reviewing the launch-day animations for the
new Dhaka Stock Exchange website: the loading screen, and seven options for how
the site opens on launch day.

Everything on it runs live in the browser rather than as a recording, and its
CSS is taken verbatim from the components that ship with the site, so what you
see here is what the site actually does.

Open `index.html`, or view it at the Pages URL for this repository.
